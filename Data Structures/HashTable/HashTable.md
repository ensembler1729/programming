#### Hash Table

Time Complexity:
| Operation | Average Case | Worst Case |
| --------- | ------------ | ---------- |
| Insert    | O(1)         | O(n)       |
| Search    | O(1)         | O(n)       |
| Delete    | O(1)         | O(n)       |
| Resize    | O(n)         | O(n)       |

<br>

Space Complexity: O(n)
